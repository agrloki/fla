# Анализ логов двигателя

Локальное веб-приложение для просмотра CSV-логов Peugeot/EP6, построения графиков и автоматического анализа. Данные не отправляются в интернет, сервер слушает только `127.0.0.1`.

Корневая папка приложения — `fla`. Все команды ниже выполняются из неё.

## Требования

- Python 3.8 или новее — для локального сервера.
- Современный браузер: Chrome, Edge, Firefox или Safari.
- Python-пакеты и Node.js не требуются: Plotly уже включён в `vendor/`.
- Интернет для работы приложения не нужен.

## Быстрый запуск

### Linux

```bash
./install.sh
./start.sh
```

Для пункта в меню приложений:

```bash
./install.sh --desktop
```

### macOS

Дважды щёлкните `start.command`. При первом запуске macOS может попросить подтвердить открытие: правый клик → «Открыть».

Либо в терминале:

```bash
./install.sh
./start.sh
```

### Windows

1. Установите Python 3.8+ с https://www.python.org/downloads/windows/.
2. При установке включите **Add Python to PATH**.
3. Запустите `install.bat`.
4. Запускайте приложение через `start.bat`.

Ярлык на рабочем столе:

```bat
install.bat --desktop
```

## Как пользоваться

1. Запустите приложение. Браузер откроется автоматически.
2. Нажмите «Открыть CSV» или перетащите файл в окно.
3. Если CSV лежат в папке `fla`, они появятся в выпадающем списке.
4. Для отчёта нажмите «Автоматический анализ», затем «Экспорт PDF» и выберите «Сохранить как PDF» в диалоге печати.

Сервер автоматически выбирает свободный порт, начиная с `8765`. Адрес выводится в терминале. Для остановки нажмите `Ctrl+C`.

## Перенос на другой компьютер

Скопируйте всю папку приложения, включая `index.html`, `css/`, `js/`, `vendor/`, `serve.py` и скрипты запуска. Затем выполните установку для нужной системы.

Можно открыть `index.html` напрямую без Python: выбор CSV вручную и анализ будут работать, но список файлов рядом с приложением и API будут недоступны.

## Сборка переносимого архива

```bash
python3 make-dist.py
```

Архив появится в `dist/`. По умолчанию CSV-логи не включаются. Чтобы добавить их:

```bash
python3 make-dist.py --with-samples
```

## Состав проекта

- `index.html` — интерфейс приложения.
- `css/styles.css` — оформление.
- `js/` — разбор CSV, графики, каналы и автоматический анализ.
- `vendor/` — локальная копия Plotly и лицензия.
- `serve.py` — локальный HTTP-сервер и API списка CSV.
- `start.sh`, `start.command`, `start.bat` — запуск.
- `install.sh`, `install.bat` — проверка окружения и подготовка к запуску.
- `make-dist.py` — сборка ZIP для переноса.

## Если что-то не работает

- **Python не найден.** Установите Python 3.8+ и повторите установку.
- **Браузер не открылся.** Откройте адрес из терминала вручную, например `http://127.0.0.1:8765/`.
- **Порт занят.** Сервер сам попробует следующие порты; смотрите фактический адрес в терминале.
- **Нет файлов в списке.** Положите `.csv` или `.txt` в папку приложения и перезапустите сервер либо выберите файл кнопкой «Открыть CSV».
- **PDF не сохраняется.** В диалоге печати выберите принтер «Сохранить как PDF» / «Microsoft Print to PDF».
